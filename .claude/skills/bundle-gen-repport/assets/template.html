What each agent does, and what holds it back

Eight agents, read straight from their OKF bundles: the agent file, every task, every prompt, every tool and knowledge note. Pick an agent, then a task, to see how a turn runs, what it may call and the rules its prompt sets.

Documentation was not used. Rules are paraphrased from the prompts and bundle notes.

Names are shown as each bundle declares them. A few capabilities appear under two names (for example search_confluence and confluence.page.search), which the prompts themselves use interchangeably, so the comparison groups them. A hollow marker means a task declares the tool but the bundle holds no note describing it.
